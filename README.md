# MiniMax H3 剧本一键生成视频

把一份剧本，推进成一组真正可以观看、审阅、继续生产的竖屏视频片段。

这个 skill 面向希望把文字创意快速变成视觉成片的创作者：它会理解故事、整理角色与场景、校准画面和声音，再交给本地 MiniMax H3 生成独立片段。复杂的叙事被拆成清晰可控的镜头单元，人物、资产和声音保持连续，最终产出足以直接进入后续制作的画面素材。

## 它能带来什么

- 让剧本从“能读”跃迁到“能看”，快速形成完整的视觉执行骨架。
- 让角色、场景、道具、声音和镜头关系变得稳定、可追踪、可复用。
- 让每个视频片段都具备独立交付价值，适合反复审阅、迭代和组合成系列内容。
- 让一次创作从灵感起步，直达接近成片的状态。

## 工作方式

从剧本理解开始，逐步收敛到资产、镜头与提示词；在关键节点保留创作者的确认权，确认后的内容再进入本地 H3 生成。每个片段独立输出，保留完整的提示词、资产清单和检查结果，让创作过程既有速度，也有证据链。

## 适合场景

短剧、漫剧、分镜预演、角色测试、概念片、广告样片，以及任何需要把中文剧本快速推进到可视化阶段的项目。

## 使用

将本目录作为 `$minimax-h3-script-to-video` skill 安装或引用即可。
